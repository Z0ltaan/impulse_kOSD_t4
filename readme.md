# impulse kvadraOS Desktop (команда 4) тестовое задание

## Начальные требования

- CMake 3.22+
- Make или другая билд система, поддерживаемая CMake
- C++17 компилятор

## Сборка

Из корневой директории проекта:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```
